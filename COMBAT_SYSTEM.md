# 🎯 Боевая система - Полная документация

## 🎮 Обзор

Реализована полноценная боевая система с:
- 💚 **Система здоровья** (HP) для всех персонажей
- 💥 **Система урона** от выстрелов
- 🤖 **AI стрельба** - NPC автоматически стреляют в противников
- 📊 **Визуальные HP-бары** над каждым персонажем
- ⚰️ **Система смерти** с плавным исчезновением

---

## ✨ Возможности

### Для игрока:
- ✅ 100 HP при старте
- ✅ Может стрелять (ПРОБЕЛ)
- ✅ Каждое попадание = 10 урона
- ✅ HP-бар над головой (зеленый → желтый → красный)
- ✅ Получает урон от врагов

### Для врагов (NPC):
- ✅ 100 HP при старте
- ✅ Автоматически обнаруживают противников (радиус 10-12 единиц)
- ✅ Автоматически стреляют (интервал 1.2-1.5 секунд)
- ✅ Умные - целятся и следуют за целями
- ✅ Оранжевые пули (отличаются от игрока)
- ✅ HP-бар показывает текущее здоровье

---

## 🎯 Геймплей

### Управление:
| Клавиша | Действие |
|---------|----------|
| W/A/S/D | Движение |
| ПРОБЕЛ  | **Стрельба** |

### Механика боя:
1. **Игрок** стреляет желтыми пулями
2. **Враги** стреляют оранжевыми пулями
3. Попадание = **-10 HP**
4. Здоровье 0 = **Смерть** (плавное исчезновение)
5. HP-бары меняют цвет:
   - 💚 **Зеленый**: > 60% HP
   - 💛 **Желтый**: 30-60% HP
   - ❤️ **Красный**: < 30% HP

### Новые компоненты (`engine/ecs/components.h`)

#### 1. Health - Здоровье
```cpp
struct Health {
    float current = 100.f;  // Текущее HP
    float maximum = 100.f;  // Максимальное HP
    bool isDead = false;    // Флаг смерти
};
```

#### 2. Damage - Урон снаряда
```cpp
struct Damage {
    float amount = 10.f;              // Количество урона
    entt::entity owner = entt::null;  // Кто выстрелил
    bool hasOwner = false;            // Установлен ли владелец
};
```

#### 3. AICombat - AI боевое поведение
```cpp
struct AICombat {
    float shootCooldown = 0.f;           // Таймер перезарядки
    float shootInterval = 1.5f;          // Интервал между выстрелами
    float detectionRange = 10.f;         // Радиус обнаружения
    float shootingRange = 8.f;           // Радиус стрельбы
    entt::entity target = entt::null;    // Текущая цель
    bool hasTarget = false;              // Есть ли цель
};
```

#### 4. Dead - Тег смерти
```cpp
struct Dead {}; // Пустой тег для мертвых сущностей
```

### Новые системы (`engine/ecs/systems.cpp`)

#### 1. damageSystem() - Обработка урона
**Что делает:**
- Проверяет столкновения пуль с персонажами
- Наносит урон при попадании
- Не позволяет стрелять в себя
- Уничтожает пули при попадании
- Помечает убитых как Dead

**Код:**
```cpp
void damageSystem(entt::registry &registry) {
    auto projectiles = registry.view<const Position, const Projectile, const Damage>();
    auto damageable = registry.view<Position, Health>(entt::exclude<Dead>);
    
    for (auto bullet : projectiles) {
        for (auto entity : damageable) {
            // Не стреляем в себя
            if (damage.hasOwner && damage.owner == entity) continue;
            
            // Проверка дистанции (радиус попадания 0.6)
            if (distance < 0.6f) {
                health.current -= damage.amount;
                if (health.current <= 0.f) {
                    registry.emplace<Dead>(entity);
                }
                // Уничтожить пулю
            }
        }
    }
}
```

#### 2. healthBarSystem() - Отображение HP
**Что делает:**
- Рисует HP-бары над всеми живыми персонажами
- Фон: темно-красный
- Заполнение: зеленый/желтый/красный (зависит от HP%)
- Рамка: черная
- Размер: 50x6 пикселей
- Позиция: на 40 пикселей выше персонажа

**Визуализация:**
```
Персонаж на 100% HP:
[████████████████] 💚

Персонаж на 50% HP:
[████████--------] 💛

Персонаж на 20% HP:
[███-------------] ❤️
```

#### 3. aiCombatSystem() - AI стрельба
**Что делает:**
- Ищет ближайшего врага в радиусе обнаружения
- Поворачивается к цели
- Стреляет, если цель в радиусе стрельбы
- Соблюдает интервал между выстрелами
- Создает оранжевые пули

**Логика:**
```
1. Сканировать область (detectionRange)
2. Найти ближайшего врага
3. Если враг в зоне стрельбы (shootingRange):
   - Повернуться к врагу
   - Если перезарядка готова:
     * Выстрелить
     * Сбросить таймер
```

#### 4. deathSystem() - Обработка смерти
**Что делает:**
- Плавно уменьшает прозрачность мертвых персонажей
- Полностью удаляет их через ~1 секунду
- Визуальный эффект: исчезновение

## 🔧 Интеграция в игру

### В `game_loop.cpp`:

```cpp
// Инициализация персонажей с HP и оружием
void GameLoop::init() {
    // Игрок
    auto player = createNPC(...);
    registry.emplace<Health>(player, 100.f, 100.f);
    registry.emplace<Weapon>(player, fireRate, bulletSpeed);
    registry.emplace<WeaponDisplay>(player, ...);
    
    // Враги
    auto enemy = createNPC(...);
    registry.emplace<Health>(enemy, 100.f, 100.f);
    registry.emplace<Weapon>(enemy, fireRate, bulletSpeed);
    registry.emplace<WeaponDisplay>(enemy, ...);
    registry.emplace<AICombat>(enemy, shootInterval, ranges...);
}

// Обновление систем
void GameLoop::update(input, dt) {
    aiCombatSystem(registry, input, dt);    // AI стрельба
    weaponSystem(registry, input, dt);      // Стрельба игрока
    projectileSystem(registry, ...);        // Движение пуль
    damageSystem(registry);                 // Обработка урона
    deathSystem(registry);                  // Смерть
    // ... другие системы
}

// Рендеринг
void GameLoop::collectRenderData(frame, camera) {
    renderSystem(...);              // Персонажи
    weaponDisplaySystem(...);       // Оружие
    healthBarSystem(...);           // HP-бары (поверх всего)
}
```

## ✨ Что нового?

### 🔫 Система оружия
- Персонаж теперь носит пистолет
- Оружие видно на экране и меняет положение в зависимости от направления
- При стрельбе - анимация вспышки

### 💥 Стрельба
- Направленная стрельба (4 направления)
- Желтые светящиеся пули
- Эффект отдачи при выстреле
- Автоматическая перезарядка

### 🎨 Визуальные эффекты
- Анимация вспышки выстрела (4 кадра)
- Динамическое положение оружия
- Плавные переходы анимаций
- Свечение пуль

### 🔧 Физика
- Пули сталкиваются со стенами
- Автоуничтожение пуль через 3 секунды
- Реалистичная траектория полета

## 🐛 Устранение неполадок

### Игра не запускается
```bash
# Пересоберите проект
cd /home/danil/McLaren
./scripts/build.sh --release --without-tests
```

### Ошибка компиляции
```bash
# Проверьте зависимости SFML
sudo apt install libsfml-dev
```

### Не отображается графика (WSL)
```bash
# Убедитесь, что X Server запущен
# Экспортируйте DISPLAY
export DISPLAY=:0
```

# Система оружия для McLaren Engine

## 🎮 Обзор

Реализована полноценная система оружия с визуальными эффектами для изометрического движка McLaren. Персонаж теперь может стрелять из пистолета с анимацией выстрела, эффектами и физикой снарядов.

## ✨ Реализованные функции

### 1. **Система оружия** (`Weapon` компонент)
- Скорострельность (настраиваемая)
- Скорость снарядов
- Автоматическое управление анимацией стрельбы
- Эффект отдачи при выстреле

### 2. **Система снарядов** (`Projectile` компонент)
- Физика движения снарядов
- Автоматическое уничтожение по таймеру
- Коллизии со стенами и препятствиями
- Направленная стрельба (зависит от направления взгляда)

### 3. **Визуальная система**
- **WeaponDisplay**: Отображение оружия рядом с персонажем
- Динамическая смена спрайта при стрельбе
- Анимация вспышки выстрела (4 кадра)
- Корректная ориентация оружия в зависимости от направления

### 4. **Анимации**
- Анимация простоя пистолета
- Анимация выстрела с эффектом вспышки
- Плавный переход между состояниями
- Временные визуальные эффекты

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| `W` | Движение вверх |
| `A` | Движение влево |
| `S` | Движение вниз |
| `D` | Движение вправо |
| `ПРОБЕЛ` | **Стрельба из пистолета** |

**Примечание**: Направление стрельбы зависит от последнего направления движения персонажа.

### Компоненты (`engine/ecs/components.h`)
```cpp
// Оружие
struct Weapon {
    float fireRate;           // Скорость стрельбы
    float timeSinceLastShot;  // Таймер перезарядки
    float bulletSpeed;        // Скорость пули
    int shootAnimationState;  // ID анимации стрельбы
};

// Снаряд
struct Projectile {
    sf::Vector2f direction;   // Направление полета
    float lifetime;           // Время жизни
    float timeAlive;          // Прожитое время
};

// Визуальное отображение оружия
struct WeaponDisplay {
    std::string textureName;  // Текстура оружия
    sf::Vector2f offset;      // Смещение от персонажа
    sf::Vector2f size;        // Размер спрайта
};

// Состояние стрельбы
struct IsShooting {
    float animationTime;      // Время анимации
};
```

## ⚙️ Настройка параметров

Вы можете настроить параметры оружия в файле `game/loops/game_loop.cpp`:

```cpp
engine::Weapon weapon;
weapon.fireRate = 0.3f;      // Время между выстрелами (секунды)
weapon.bulletSpeed = 20.f;   // Скорость пули
weapon.shootAnimationState = 2;  // ID анимации стрельбы
```

Для изменения внешнего вида оружия:

```cpp
engine::WeaponDisplay weaponDisplay;
weaponDisplay.textureName = "game/assets/weapons/pistol-idle.png";
weaponDisplay.offset = {0.3f, -0.1f};  // Позиция относительно персонажа
weaponDisplay.size = {24.f, 24.f};     // Размер отображения
```

## 🔧 Технические детали

### Архитектура
Система оружия полностью интегрирована в ECS архитектуру движка McLaren:
- **Компоненты** хранят данные оружия, снарядов и визуализации
- **Системы** обрабатывают логику стрельбы, физику и рендеринг
- **Интеграция** происходит через GameLoop без модификации ядра движка

### Порядок выполнения систем
```
1. playerInputSystem     - Обработка ввода игрока
2. weaponSystem          - Обработка стрельбы (новое!)
3. projectileSystem      - Обновление снарядов (новое!)
4. npcFollowPlayerSystem - AI следования
5. npcWanderSystem       - AI блуждания
6. movementSystem        - Физика движения
7. animationSystem       - Обновление анимаций
8. gameAnimationSystem   - Игровые анимации
```

### Система коллизий
Снаряды проверяют коллизии с:
- Границами карты
- Твердыми тайлами (solid tiles)
- При столкновении снаряд уничтожается

### Визуальный рендеринг
1. **Рендеринг персонажа** (renderSystem)
2. **Рендеринг оружия** (weaponDisplaySystem) - поверх персонажа
3. **Рендеринг снарядов** (renderSystem) - как обычные entities

## 🎨 Визуальные эффекты

### Эффект вспышки
При выстреле воспроизводится 4-кадровая анимация с постепенным затуханием:
- Кадр 0: Большая яркая вспышка
- Кадр 1: Средняя вспышка
- Кадры 2-3: Обычный пистолет

### Эффект отдачи
При выстреле персонаж слегка откатывается назад, создавая ощущение импульса.

### Динамическая ориентация
Оружие автоматически поворачивается в зависимости от направления взгляда персонажа:
- **Вниз**: оружие впереди и ниже
- **Вправо**: оружие справа
- **Влево**: оружие слева
- **Вверх**: оружие впереди и выше

## 📊 Производительность

Система оптимизирована для работы с:
- Множественными снарядами на экране
- Частой стрельбой
- Коллизиями в реальном времени

Снаряды автоматически удаляются через 3 секунды или при столкновении, предотвращая накопление entities.
